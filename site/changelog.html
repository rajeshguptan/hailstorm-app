Changelog

Release notes and version history for Hailstorm. All releases include security updates for applicable license holders.

Initial Release

First stable release of Hailstorm with core API testing capabilities.

  • Multi-protocol support (REST/HTTP1.1, HTTP/2)
  • Authentication vault (OAuth2, Bearer Tokens, API Keys, AWS Signature)
  • Dynamic environments (Global, Environment, Local variables)
  • Pre-request scripting with JavaScript
  • Test assertions and validation
  • Collection runner with data-driven testing (CSV/JSON)
  • Built-in load testing engine
  • Real-time telemetry (latency p95/p99, throughput RPS, error rates)
  • Git-friendly collection format
  • Local-first storage (no cloud sync required)
  • Dark mode interface
  • Import from Postman and OpenAPI specifications
