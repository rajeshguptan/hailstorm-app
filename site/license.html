License Framework

Three distinct license tiers that may be combined for cumulative rights

License Tiers

Hailstorm employs a tiered licensing model where licenses may be combined to provide cumulative rights. Each license builds upon the previous tier, granting expanded capabilities while maintaining the core "non-transferable" restriction across all levels.

1. User License ($9.99)

Base license for individual users

  • Lifetime license with all future updates included
  • Security fixes included
  • Non-transferable
  • Intended for: Personal API testing workflows, individual developers

2. Patron License ($100)

Includes everything in User License, plus:

  • Vote on new features (1 vote included)
  • Shape the future of Hailstorm
  • Support ongoing development
  • Non-transferable
  • Intended for: Users who want to influence product direction and support development

3. Developer License ($1,000)

Includes everything in Patron License, plus:

  • Complete source code access
  • Modify for your requirements
  • Integrate into internal tools
  • Internal use permitted
  • No resale or redistribution
  • Intended for: Organizations requiring source code access and customization

License Combination: Licenses are designed to stack. Purchasing multiple tiers grants the additive rights of all purchased licenses. All licenses are distributed exclusively through Lemon Squeezy and provide security updates as part of the license grant.
